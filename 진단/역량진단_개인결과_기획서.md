# 역량진단 개인결과 페이지 기획서

> **프로젝트**: LABS 3.0 — 범용 역량진단  
> **페이지 ID**: 미정  
> **작성 기준**: 프로토타입 `역량진단_개인결과.html` 기반  
> **최초 작성**: 2026-05-27  

---

## 1. 개요

### 1.1 목적
역량진단(범용)에 참여한 대상자 본인이 자신의 진단 결과를 확인하는 개인 결과 열람 페이지.  
역량군별 강점/약점 분류, GAP 분석, 다면평가 비교, 사전-사후 변화 추이를 단일 페이지에서 제공한다.

### 1.2 서비스 위치
```
my Canvas > 진단 > 진단 목록 > [결과 보기] → 역량진단 개인결과 페이지
```

### 1.3 대상 사용자
- **접근 가능**: 진단 대상자 본인
- **접근 불가**: 타인(관리자 포함 별도 경로 확인 필요)

### 1.4 관련 화면
| 화면 | 방향 | 비고 |
|------|------|------|
| 진단 목록 (진단_연수원.html) | 진입 | "결과 보기" 버튼에서 진입 |
| PDF 출력 | 나가기 | 우측 상단 PDF 저장 버튼 |

## 3. URL 파라미터 및 화면 분기 로직

### 3.1 파라미터 정의
| 파라미터 | 값 | 설명 |
|----------|------|------|
| `diagnosisId` | 진단 고유 ID | 필수 |
| `modelType` | `1` / `2` | 1=본인진단, 2=다면평가 |

### 3.2 VIEW 분기 흐름

```
진입
 ├── modelType=1 (본인진단)
 │    ├── 동일 역량분야의 사전진단 결과 없음  →  VIEW ① 본인진단만 표시
 │    └── 동일 역량분야의 사전진단 결과 있음  →  VIEW ① + VIEW ③ 탭 노출
 │                                              (기본: VIEW ① 표시, ③ 탭 클릭 시 전환)
 └── modelType=2 (다면평가)
      └── VIEW ② 다면평가만 표시
```

### 3.3 사전/사후 매핑 기준
- **동일 역량분야(역량군 설정 기준)** 의 이전 진단 결과가 존재하면 사후 비교 탭(VIEW③) 자동 노출
- 매핑 판단은 역량분야 식별자(ID) 기준으로 BE에서 처리 _(BE 협의 필요)_

## 5. VIEW별 상세 화면 기획

### 5.1 VIEW ① — 본인진단 (modelType=1, 사전 또는 단독)

#### 5.1.1 종합 평가 카드
3열 그리드 구성:

| 영역 | 내용 |
|------|------|
| **강점 역량** (파랑 배경) | 강점 도달 기준 이상인 역량군 목록 + 점수 + 기준값 표시 |
| **약점 역량** (빨강 배경) | 약점 기준 이하인 역량군 목록 + 점수 + 기준값 표시 |
| **종합 평균** (회색 배경) | 본인 전체 평균 / 5.0점, 전체평균 병기 |

#### 5.1.2 역량군별 종합 지수 차트
- **차트 유형**: 수평 막대 차트 (역량군 단위)
- **표시 막대**: 본인(파랑), 전체평균(회색) — 2개 막대 per 역량군
- **임계값 표시**: 역량군별 강점 기준선(파랑 점선), 약점 기준선(빨강 점선) 오버레이
- **배지 표시**: 강점/약점 판정된 역량군에 컬러 배지 표시
- **범례**: 본인, 전체평균, 강점 기준, 약점 기준

**점수 컬러 규칙**:
- 강점 역량군의 본인 점수 → 파랑(`--blue`)
- 약점 역량군의 본인 점수 → 빨강(`--red`), 막대 색상도 빨강

#### 5.1.3 역량 상세 결과 테이블

| 컬럼 | 내용 |
|------|------|
| 역량군 | colspan 행 (배경색 구분, 좌측 파랑 보더), 강점/약점 배지, 기준값 병기 |
| 역량명 | 세부 역량 항목명 |
| 본인 | 세부 역량 본인 점수 (강점 파랑, 약점 빨강) |
| 전체평균 | 전체 참여자 평균 |
| GAP | 본인 − 전체평균 (양수 파랑, 음수 빨강, 0 회색) |

**메타 카드 응답자 현황**: "본인 완료"

---

### 5.2 VIEW ② — 다면평가 (modelType=2)

#### 5.2.1 종합 평가 카드
- 강점 역량: 전사평균 기준 강점 도달 역량군 _(기준 협의 필요 — 본인 점수? 전사평균?)_
- 약점 역량: 본인 자기평가 기준 약점 역량군 + "타인 평가와 큰 인식 차이 존재" 경고 문구 (차이 기준 협의 필요)
- 종합 평균: 본인 / 상사 / 동료 / 구성원 / 전사평균 각각 표시 (개행 목록)

#### 5.2.2 역량군별 종합 지수 차트 (평가자별 비교)
- **표시 막대**: 본인(파랑), 상사(주황), 동료(보라), 구성원(초록), 전사평균(회색) — 최대 5개 막대 per 역량군
- 진단 설정에서 포함된 평가자 유형만 표시 (미포함 유형 막대 숨김)
- **임계값 표시**: 강점/약점 기준선 (VIEW①과 동일)
- **범례**: 평가자별 색상 범례 표시

#### 5.2.3 역량 상세 결과 테이블 (평가자별 비교)

| 컬럼 | 내용 |
|------|------|
| 역량군 | colspan 행 (기준값 병기, 강점/약점 배지) |
| 역량명 | 세부 역량명 |
| 본인 | 자기평가 점수 |
| 상사 | 상사 평가 점수 (미포함 시 열 숨김) |
| 동료 | 동료 평가 점수 (미포함 시 열 숨김) |
| 구성원 | 구성원 평가 점수 (미포함 시 열 숨김) |
| 전사평균 | 전사 평균 점수 |
| GAP | 본인 − 전사평균 (인식 차이 지표) |

**메타 카드 응답자 현황**: "본인 + 상사 N · 동료 N · 구성원 N"

---

### 5.3 VIEW ③ — 사후진단 (전/후 비교)

> VIEW③은 동일 역량분야에 사전진단 결과가 있을 때만 탭 노출 (modelType=1 전용)

#### 5.3.1 종합 평가 카드
- 강점/약점: 사후진단 결과 기준으로 판정, 사전 대비 변화(±) 함께 표시
- 종합 평균: 사후 점수 / 5.0점 + "사전 대비 +X.XX 향상" 변화 표시 + 사전 점수 병기

#### 5.3.2 사전·사후 비교 카드
- 좌우 2열 카드: 사전 진단(회색 배지) / 사후 진단(초록 배지)
- 각 카드: 역량군별 점수 나열 (사후 기준 강점 파랑, 약점 빨강)
- 하단 변화 테이블:

| 컬럼 | 내용 |
|------|------|
| 역량군 | 역량군명 |
| 사전 | 사전 점수 |
| 사후 | 사후 점수 |
| 변화 | 사후 − 사전 (양수 파랑, 음수 빨강) |
| 추이 | ▲ 향상 / ▼ 악화 / = 유지 |

#### 5.3.3 역량 상세 결과 테이블

| 컬럼 | 내용 |
|------|------|
| 역량군 | colspan 행 (강점/약점 배지) |
| 역량명 | 세부 역량명 |
| 사전 | 사전 점수 (약점 기준 이하 빨강) |
| 사후 | 사후 점수 (강점 파랑, 약점 빨강) |
| 전체평균 | 전체 참여자 평균 |
| 변화 | 사후 − 사전 |
| GAP | 사후 − 전체평균 |

**메타 카드**: "사전 진단" 항목으로 교체 → "YYYY.MM 완료" 표시

## 6. 강점 / 약점 판정 기준

### 6.1 기준 설정 주체
관리자가 진단 생성 시 **역량군(역량영역)별로 개별 설정**. 전체 공통 기준 없음.

| 설정값 | 설명 |
|--------|------|
| **강점 도달 점수** | 역량군 평균 ≥ 이 값이면 강점 판정 |
| **약점 점수** | 역량군 평균 ≤ 이 값이면 약점 판정 |

### 6.2 판정 로직 (역량군 단위)
```
if 역량군 평균 >= 강점도달점수 → 강점 배지 (파랑)
elif 역량군 평균 <= 약점점수    → 약점 배지 (빨강)
else                            → 배지 없음 (보통)
```

### 6.3 VIEW별 판정 기준값 적용 대상
| VIEW | 판정 기준 점수 | 비고 |
|------|--------------|------|
| VIEW ① (본인진단) | 본인 자기평가 역량군 평균 | |
| VIEW ② (다면평가) | **협의 필요** — 전사평균? 본인? | ⚠️ 기획 결정 필요 |
| VIEW ③ (사후진단) | 사후 자기평가 역량군 평균 | |

## 7. GAP 정의

| VIEW | GAP 계산식 | 의미 | 컬럼명 |
|------|-----------|------|--------|
| VIEW ① 본인진단 | 본인 − 전체평균 | 집단 내 상대적 위치 | GAP |
| VIEW ② 다면평가 | 본인(자기평가) − 전사평균 | 자기인식 vs 타인인식 차이 | GAP |
| VIEW ③ 사후진단 | ① 사후 − 사전 = 변화<br>② 사후 − 전체평균 = GAP | 성장 측정 + 현재 위치 | 변화 / GAP |

**표시 규칙**:
- 양수(+): 파랑(`--blue`)
- 음수(-): 빨강(`--red`)
- 0: 회색(`--text-400`)

## 8. 평가자 유형

### 8.1 지원 유형
| 유형 | 식별 | 색상 | 비고 |
|------|------|------|------|
| 본인 | self | `--primary` (#246CF9) | 자기평가 |

| 전사평균 | comp | `#94A3B8` (회색) | 전체 대상자 평균 (본인 포함 여부 BE 확인) |

### 8.2 유형별 표시 제어
- 진단 설정에서 포함된 평가자 유형만 차트 막대 및 테이블 컬럼 표시
- 미포함 유형은 자동 숨김 (컬럼 제거, 막대 제거)

## 10. 미정 / 협의 필요 항목

| # | 항목 | 내용 | 우선순위 |
|---|------|------|---------|
| 1 | 다면평가 강점/약점 기준 | 역량군 강점/약점 판정 시 어떤 점수 기준 적용? (본인 자기평가 / 전사평균 / 타인평균) | 높음 |
| 2 | 사전/사후 매핑 조건 | 동일 역량분야 판단 기준 (역량분야 ID? 역량군 구성 동일 여부?) | 높음 |
| 3 | 다면평가 진입 최소 응답자 수 | 결과 열람 가능 최소 타인 응답자 수 | 높음 |

| 6 | 차트 임계값 선 표시 방식 | 점선 오버레이 유지 vs 범례 텍스트 대체 여부 | 낮음 |
| 7 | 소수점 자리수 | 역량군 / 세부 역량 점수 소수 첫째 자리 vs 둘째 자리 | 낮음 |
| 8 | 모바일 대응 | 테이블 가로 스크롤 vs 카드형 전환 | 낮음 |
| 9 | PDF 세부 스펙 | 별도 기획서 필요 (차트 렌더링, 페이지 레이아웃 등) | 중간 |
