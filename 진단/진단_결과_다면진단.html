기획 스펙 노트 (실제 서비스 미노출)

1. 진입 조건

  • 진단 대상자 본인만 접근 가능
  • 본인 응답 완료 + 관리자 마감 처리 완료 시 결과 열람 가능

2. 응답자 구분 표시 순서 · 숨김

  • 진단 만들기 STEP2 응답자 유형 선택 순서(본인 → 구성원 → 상사 → 동료)와 동일하게 종합 점수 목록·차트·표 컬럼·서술형 블록에 일괄 적용
  • 진단 설정에 포함되지 않은 유형은 차트 시리즈·표 컬럼·서술형 응답·인식 차이 계산에서 모두 제외

3. 종합 평가

  • 역량군별 종합 점수 = 해당 역량군의 본인 + 응답자 유형 점수의 평균 (역량군 종합 점수의 평균 = 종합 종합 점수)
  • 종합 점수 · 본인 · 구성원 · 상사 · 동료를 줄마다 가로 막대로 표시(순서 고정, 점수와 GAP = 점수 − 전체평균 병기) / 전체평균은 모든 줄을 관통하는 점선 / 축은 0 ~ 5 고정 / 설정된 응답자 유형만 표시
  • 역량군이 2개 이상이면 역량군별 점수 세로막대(역량군마다 종합 점수 · 본인 · 구성원 · 상사 · 동료 막대를 묶어서 표시, 전체평균 가로선, GAP = 종합 점수 − 전체평균)를 추가 노출
  • 종합 점수는 종합 점수 = 본인 + 설정된 응답자 유형(구성원·상사·동료) 점수의 평균(유형별 동일 가중)
  • 유형·역량군 점수 = 소속 세부역량 점수의 평균, 응답자 구분별 종합 = 역량군 점수의 평균 (전체평균 동일 산식)

4. 종합 평가 코멘트 노출 규칙

  • 고정 문장 + 실제 점수 치환 (AI 생성 아님)
  • ① 종합 점수과 전체평균의 차이 — 항상 노출
  • ② 타인(구성원·상사·동료 중 설정된 유형) 평가 평균과 본인 점수의 차이 — 항상 노출, 차이 0.1점 미만이면 "비슷해요"
  • ③ 가장 강점인 / 가장 보완이 필요한 역량군 — 역량군이 2개 이상일 때 노출 / 역량군이 1개일 때만 가장 높은 / 낮은 세부역량 문장으로 대체 (동시 노출 금지)
  • ④ 추천 과정 안내 — 보완이 필요한 세부역량이 1개 이상일 때 노출

5. 강점 / 약점 판정 기준

  • 역량군별로 진단 생성 시 관리자가 설정한 강점 도달 점수(이상) / 약점 점수(미만)(1~5점)를 종합 점수(본인 + 응답자 유형 점수의 평균)에 적용 — 세부역량 · 역량군 모두 동일 / 하나의 역량군이 강점·약점 양쪽에 나타날 수 있음
  • 강점 · 약점 역량 섹션, 종합 평가 코멘트(가장 강점인 / 보완이 필요한 역량군), 추천 과정 대상 모두 종합 점수 기준 / 역량별 지수 그래프는 종합 점수 점의 색(파랑=강점 · 검정=보통 · 빨강=약점)과 강점·약점 기준선으로 표시하며, 역량 상세 결과는 세부역량 종합 점수가 강점 도달 점수 이상이면 강점(파랑 배지·행 배경·종합 점수 색), 약점 점수 미만이면 약점(빨강)으로 표시

6. 인식 차이

  • 세부역량별로 본인 점수 − 타인 평균을 계산 (타인 평균 = 설정된 타인 유형 점수의 단순 평균)
  • 차이가 양수이면 "본인이 더 높게 평가한 역량", 음수이면 "타인이 더 높게 평가한 역량"으로 구분해 각각 차이가 큰 순 최대 3개 노출, 해당 없으면 "차이가 큰 역량이 없어요"

7. 과정 추천

  • 자가진단과 동일 — 약점 기준 미만 세부역량을 전체평균과 차이가 큰 순으로 먼저 선정하고 2개 미만이면 나머지 세부역량 중 전체평균 대비 낮은 순으로 채워 항상 1순위 · 2순위(약점도 아니고 전체평균보다 낮지도 않은 항목은 "역량 강화를 위한 영역"으로 안내), 세부역량마다 영역 카드(추천 사유 + 연계된 이러닝 과정 좌우 이동)로 노출, 사유의 점수는 종합 점수 기준 / [추천과정 전체보기] 시 우측 패널

8. 서술형 응답

  • 점수에 반영되지 않으며, 질문별로 본인 → 본인 외 응답 순서로 원문 노출
  • 본인 외 응답은 구성원·상사·동료 구분 없이 응답자1, 응답자2…로만 표기하고, 이름·소속·유형 등 식별 정보는 노출하지 않음 / 노출 순서는 유형이 드러나지 않도록 제출 순서와 무관하게 섞음

9. 역량별 지수 · 역량 상세 결과 · GAP

  • 역량별 지수: 종합 점수(종합) 기준 세부역량별 슬라이더 그래프와 우측 종합 점수 · 전체평균 · GAP(종합 점수 − 전체평균) 수치 열을 함께 노출 — 종합 점수 점의 색(파랑=강점 · 검정=보통 · 빨강=약점)과 강점·약점 기준선, 전체평균 눈금을 표시 (수치는 점에 마우스를 올리면 툴팁으로 확인) / 역량 상세 결과: 세부역량별 종합 점수 · 본인 · 구성원 · 상사 · 동료 · 전체평균 숫자만 노출, 본인 · 구성원 · 상사 · 동료 · 전체평균 점수 하단에 GAP(종합 점수 − 해당 점수)을 함께 표기, 종합 점수에는 GAP 없음 — 두 영역을 분리하여 사전사후 비교 시 각각 그래프(전/후 겹침)와 표(전/후 수치)로 확장
  • GAP = 종합 점수 − 해당 점수 (본인 · 구성원 · 상사 · 동료 · 전체평균 각각, 종합 점수에는 없음), 양수 파란색 · 음수 빨간색 (인식 차이는 별도로 본인 − 타인 평균)
