기획 스펙 노트 (실제 서비스 미노출)

1. 진입 조건

  • 진단 대상자 본인만 접근 가능
  • 본인 응답 완료 + 구분별 최소 응답자 수 충족 + 관리자 마감 처리 완료 시 결과 열람 가능
  • 최소 응답자 수 미충족 시 "응답자가 부족합니다" 안내, 마감 전에는 "집계 중" 안내 최소 인원 값은 진단 설정에서 관리자 지정

2. 응답자 구분 표시 순서

  • 진단 만들기 STEP2 응답자 유형 선택 순서(본인 → 구성원 → 상사 → 동료)와 동일하게 차트·표·메타 영역에 일괄 적용
  • 진단 설정에서 포함되지 않은 유형은 차트 막대·표 컬럼 모두 자동 숨김

3. 문항 유형별 반영 방식

  • 척도형·A/B강제선택형(6단계→5점 정규화)은 역량군 점수에 반영, 서술형은 점수 미반영 · 하단 섹션에 별도 노출

4. 강점 / 약점 판정 기준

  • 강점: 전사평균 기준 도달 여부로 판정(예시) / 약점: 본인 자기평가 기준(예시)
  • 다면진단에서 판정 기준을 본인 점수 / 전사평균 / 타인평균 중 무엇으로 통일할지 기획 결정 필요

5. 서술형 응답 익명성 처리 (신규 정의 필요)

  • 복수 응답자 유형(구성원·동료 등)은 최소 응답자 수 미만일 때 서술형 원문을 비공개 처리 — 숫자 점수는 이미 평균으로 집계되어 노출되지만, 서술형 원문은 문체·내용만으로 특정인이 식별될 수 있어 별도 기준 필요
  • 상사처럼 통상 1인으로 배정되는 유형은 대상자가 이미 신원을 알고 있으므로 최소 인원 기준 예외로 처리(안)
  • 비공개 임계값(예시 3명), 유형별 예외 여부 모두 기획 확인 필요

6. GAP 정의 및 PDF 저장

  • GAP = 본인(자기평가) − 전사평균, 양수 파란색 · 음수 빨간색
  • PDF 저장 시 서술형 응답 포함 여부, 비공개 처리된 항목의 PDF 표기 방식 별도 스펙 필요
