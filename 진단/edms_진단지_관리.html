진단지 일괄등록

일괄등록 안내
엑셀 파일(.xlsx, .xls)로 진단지의 유형·역량군·세부역량·질문을 한 번에 등록할 수 있습니다. 최대 10MB
시트 구성: 한 행 = 한 질문. 유형명·역량군명·세부역량명이 같으면 시스템이 자동으로 계층 구조를 생성합니다.
질문유형 3종: 척도형 / A/B 강제선택 / 서술형 — 미리보기로 오류 확인 후 등록 버튼을 눌러주세요.
오류가 있는 경우 등록 버튼이 비활성화됩니다.

📥 샘플파일 다운로드
Step 2. 파일 첨부
파일을 이곳에 끌어다 놓거나 파일 선택 버튼을 클릭하세요.
📎

오류 케이스 정리
오류내용 표시방법 오류케이스 정리
데이터 없음엑셀 파일에 등록된 데이터가 없는 경우 (헤더 행 이후 데이터 없음)
필수값 누락유형명·역량군명·세부역량명·질문유형·질문내용 중 비어 있는 항목이 있는 경우
질문유형 오류'척도형', 'A/B 강제선택', '서술형' 외의 값이 입력된 경우
척도형 보기 누락질문유형이 '척도형'인데 보기1 내용(F열)이 비어 있는 경우
A/B 문구 누락질문유형이 'A/B 강제선택'인데 A 문구(P열) 또는 B 문구(Q열)가 없는 경우
점수 형식 오류척도형 점수값이 숫자가 아니거나 동일한 점수가 중복 입력된 경우
파일 용량 초과업로드 파일이 10MB를 초과한 경우
컬럼값 오류샘플 파일의 컬럼명을 변경하거나 컬럼 순서 등을 변경한 경우
파일 형식 오류.xlsx, .xls 외의 파일 형식을 업로드한 경우
