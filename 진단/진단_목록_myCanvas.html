기획 스펙 노트

① 진단 목록 노출 조건

  • 응답자로 배정된 진단 + 진단대상자로 배정된 진단을 통합 목록으로 표시
  • 진단대상자 컬럼: 본인 자기진단 → 본인 배지 표시 / 타인 평가 → 해당 인원 이름 표시
  • 진단 목록은 EDMS(리더십진단 서비스)에서 기업별로 배정된 진단 정보를 연수원 API를 통해 연동
  • 정렬 기본값: 최신 진단순(진단종료일 DESC), 진행중 우선

② 액션 버튼 상태 로직

  • 진단하기(파란색): 진행율 0%, 마감상태 N — 응답 시작 전
  • 이어하기(주황색): 진행율 1~99%, 마감상태 N — 응답 중단 후 재진입
  • 완료(비활성): 마감상태 Y 또는 진행율 100% — 수정 불가, 버튼 비활성
  • 결과보기(선 버튼): 진단대상자가 '본인'이고, 본인 응답 완료 + 타인 응답자 2인 이상 완료 조건 충족 시
  • 결과대기(비활성): 본인은 완료했으나 타인 응답자 수 조건 미충족 → 조건 미충족 안내 툴팁 표시

③ 결과보기 열람 조건 (리포트 생성 조건)

  • 조건 1: 본인(진단대상자) 응답 완료
  • 조건 2: 타인 응답자 2명 이상 완료
  • 조건 3: 진단 마감 상태 Y (EDMS에서 마감 처리 후)
  • → 위 조건 미충족 시 "결과대기" 비활성 버튼 표시 + 툴팁으로 조건 안내

④ 연동 데이터 출처

  • 진단 기본 정보(진단명, 기간, 문항수): 리더십진단 서비스(터닝포인트 CUBE®) → 연수원 API 연동
  • 진행율: 연수원 내 응답 저장 데이터 기반 실시간 계산
  • 마감상태: 리더십진단 서비스의 진단 마감 상태값 동기화
