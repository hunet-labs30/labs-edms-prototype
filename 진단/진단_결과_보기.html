기획 스펙 노트

① 결과 리포트 열람 조건 (3가지 모두 충족 필요)

  • 조건 1: 진단대상자(본인)의 자기진단 응답 완료
  • 조건 2: 타인 응답자 2명 이상 응답 완료 (익명성 보장 기준)
  • 조건 3: 진단 마감 상태 'Y' — EDMS(교육담당자)에서 마감 처리 후 리포트 생성됨
  • → 조건 충족 시 '결과보기' 버튼 활성화, 미충족 시 '결과대기' 버튼 비활성

② 리포트 임베드 방식

  • 연수원 내 iframe으로 터닝포인트 CUBE® 리포트 시스템 임베드
  • 임베드 URL: https://[CUBE_도메인]/report?token=[인증토큰]&diag_id=[진단ID]&user_id=[사용자ID]
  • 인증 토큰: 연수원 서버에서 CUBE® API 호출 → SSO 토큰 발급 → iframe URL에 포함
  • iframe 높이: 최소 700px, 리포트 콘텐츠 길이에 따라 자동 확장 (postMessage 또는 ResizeObserver 활용)
  • 보안: X-Frame-Options / CSP 허용 설정 필요 (CUBE® 측과 협의)

③ 전체화면 모드

  • '전체화면' 버튼 클릭 시 iframe을 전체 화면(또는 새 탭)으로 전환
  • 새 탭으로 열 경우 인증 토큰 URL을 그대로 전달

④ PDF 저장

  • '리포트 PDF 저장' 클릭 → CUBE® 리포트 시스템의 PDF 다운로드 기능 호출
  • 또는 연수원 서버에서 PDF 생성 API 호출 후 다운로드 제공 (CUBE® 측 API 지원 여부 확인 필요)

⑤ 조건 미충족 안내

  • 열람 조건 3개 각각의 충족 여부를 체크리스트로 표시
  • 타인 응답자 수: 실시간 카운트 표시 (현재 N명 / 필요 2명)
  • 교육담당자에게 독려 요청 안내 문구 포함

⑥ 접근 권한

  • 결과 리포트는 진단대상자 본인만 열람 가능
  • 응답자(타인 평가자)는 결과 열람 불가 (진단대상자가 아닌 경우)
  • URL 직접 접근 시 로그인 + 진단대상자 본인 여부 검증 필요
