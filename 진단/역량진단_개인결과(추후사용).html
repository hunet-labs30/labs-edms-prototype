기획 스펙 노트 (실제 서비스 미노출)

1. 페이지 진입 조건 및 접근 제어

  • 대상자 본인만 접근 가능 (타인 접근 시 권한 오류 안내)
  • 본인 응답 완료 + 마감 처리 조건을 모두 충족해야 결과 열람 가능 조건 미충족 시 안내 화면 표시
  • 다면평가(modelType=2): 본인 응답 완료 + 타인 응답 N명 이상 + 마감 처리 모두 충족 필요 (최소 응답자 수는 진단 설정에서 관리자 지정)

2. 화면 분기 로직 (URL 파라미터)

  • modelType=1: 본인진단 → VIEW ①③
  • modelType=2: 다면평가 → VIEW ②
  • 사후진단 여부는 동일 역량분야에 사전진단 결과가 존재하면 자동으로 VIEW ③ 탭 노출
  • 사전/사후 매핑은 역량분야(역량군 설정) 동일 여부로 판단 BE 확인 필요

3. 강점 / 약점 판정 기준

  • 역량군(역량영역)별로 강점 도달 점수와 약점 점수가 진단 생성 시 관리자에 의해 각각 설정됨
  • 강점: 역량군 평균 점수 ≥ 해당 역량군의 강점 도달 점수
  • 약점: 역량군 평균 점수 ≤ 해당 역량군의 약점 점수
  • 두 조건 모두 해당하지 않으면 판정 없음(보통) — 배지 미표시
  • 다면평가 시 강점/약점은 전사평균 기준으로 판정 (별도 협의 필요) 기획 확인 필요

4. GAP 정의

  • 본인진단 (VIEW①): GAP = 본인 점수 − 전체평균
  • 다면평가 (VIEW②): GAP = 본인(자기평가) − 전사평균 인식 차이 지표
  • 사후진단 (VIEW③): 변화 = 사후 점수 − 사전 점수, GAP = 사후 점수 − 전체평균
  • GAP 표시: 양수(+) 파란색, 음수(-) 빨간색, 0 회색

5. 평가자 유형 및 표시

  • 지원 평가자 유형: 본인, 상사, 동료, 구성원(부하), 전사평균
  • 진단 설정에서 포함 여부 선택 가능 → 미포함 유형 열(컬럼)은 테이블에서 자동 숨김
  • 다면평가 차트: 역량군별로 5개 이하의 가로 막대를 색상 구분하여 표시
  • 전사평균은 동일 역량분야 전체 대상자 평균 (본인 포함 여부 BE 확인) BE 확인 필요

6. PDF 저장

  • 우측 상단 "PDF 저장" 버튼 → 현재 화면 기준으로 PDF 생성 (뷰 탭별 각각 가능 여부 협의 필요)
  • PDF 내 차트 및 표 포함 여부, 페이지 레이아웃 추가 기획 필요 별도 스펙

7. 미정 / 협의 필요 항목

  • 다면평가에서 역량군별 강점/약점 판정 기준값 적용 대상: 본인 점수? 전사평균? 타인 평균? 기획 결정 필요
  • 차트 내 임계값(기준선) 표시 방식: 점선 유지 vs 범례 설명 전환 여부
  • 세부 역량 점수의 소수점 자리수 (현재 1자리 표기)
  • 모바일 화면 대응 방식 (테이블 가로 스크롤 vs 카드형 전환)
