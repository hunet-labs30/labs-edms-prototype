🔒 AI리터러시 진단 결과
이는 프로토타입입니다. 실제 서비스에서는 상품별 전용 결과 리포트가 이 영역에 렌더링됩니다.

예상 콘텐츠:
- AI리터러시 레벨별 분포
- AI도구 활용 능력 평가
- AI윤리 인식도 분석
- 맞춤형 학습 경로 제안
기획 스펙 노트: 진단 결과 셸/콘텐츠 분리

셸 (진단유형별)

  • 상시진단 — 회차 이력 UI (위의 "회차 선택" 탭)를 포함하여, 사용자가 과거 응답 회차를 선택하고 각 회차별 결과를 비교 가능
  • 자가진단 — 회차 선택 UI 없음 (1회 응답만 가능)

콘텐츠 (결과지 템플릿별)

  • 표준형 콘텐츠 — 역량군 서머리, 강점/약점, 종합지수 차트, 역량 상세 결과, 서술형 응답 (기존 디자인)
  • AI리터러시 전용 콘텐츠 — 상품 특화 결과 리포트 (현재는 플레이스홀더, 추후 실제 콘텐츠로 교체)

조합 매트릭스

  • 상시진단 + 표준형 = 회차 탭 + 역량군 서머리
  • 상시진단 + AI리터러시 = 회차 탭 + AI리터러시 결과
  • 자가진단 + 표준형 = (회차 탭 없음) + 역량군 서머리

회차 데이터 구조

  • 각 회차마다 응답 일자, 점수, 세부 점수 이력 보유
  • 회차 선택 시 해당 회차의 모든 점수·차트가 업데이트되는 방식 구현
